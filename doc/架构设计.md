### 最简架构设计

---

#### **1. 整体架构**

复制

+-------------------+     HTTP请求      +-------------------+
|   Vue 前端        |<---------------->|   Flask 后端       |
|   (响应式布局)     |   JSON交互        |   (API + 基础逻辑)  |
+-------------------+                  +-------------------+
        ↑                                     ↑
        |                                     | 数据操作
        |                                     |
+-------------------+                  +-------------------+
|   Scrapy 爬虫     |                  |   MySQL 8.0       |
|   (直接调度)       |<---------------->|   (主数据库)        |
+-------------------+   数据写入/读取    +-------------------+
                                       ↑
                                       | 缓存支持
                                       |
                                    +-------------------+
                                    |   Redis           |
                                    |   (仅缓存热门榜单)  |
                                    +-------------------+

---

#### **2. 核心组件实现**

##### **前端层（Vue）**

- **技术栈**：Vue3 + Vue Router + Axios + Element Plus

- **简化设计**：
  
  - 响应式布局：通过Flex/Grid实现PC/移动端适配，无需PWA。
  
  - 路由管理：首页、小说详情页、阅读器、个人中心等基础页面。
  
  - 数据交互：Axios直接调用Flask API，无复杂状态管理（仅用Vue组件状态）。

##### **后端层（Flask）**

- **技术栈**：Flask + SQLAlchemy

- **核心功能**：
  
  - **API接口**：直接定义路由处理用户注册、登录、小说查询、评论等操作。
  
  - **数据库交互**：SQLAlchemy ORM操作MySQL表（`user`、`novel`、`chapter`等），事务通过`db.session.commit()`实现。
  
  - **爬虫集成**：通过Flask路由手动触发Scrapy爬虫（如`/start_crawl`接口），爬虫结果直接写入MySQL临时表。
  
  - **缓存支持**：使用Redis仅缓存首页榜单（如热销榜、新书榜），通过Flask定时任务每日更新。

##### **数据层**

- **MySQL 8.0**：
  
  - **必要表结构**：
    
    - `user`：用户信息（手机/邮箱、密码哈希）。
    
    - `novel`：小说元数据（标题、分类、作者、简介）。
    
    - `chapter`：章节内容（外键关联`novel.id`）。
    
    - `comments`：评论/书评。
    
    - `payment`：支付记录（仅记录流水，无复杂积分逻辑）。
  
  - **索引优化**：为`novel.title`和`novel.category`添加复合索引，支持快速筛选。

- **Redis**：
  
  - **仅缓存榜单**：首页热销榜、新书榜数据，通过Flask定时任务从MySQL聚合后写入。

##### **爬虫层（Scrapy）**

- **简化设计**：
  
  - **直接调用**：通过Flask路由触发爬虫（非异步，单线程运行）。
  
  - **数据清洗**：爬虫结果写入`crawl_temp`表，管理员通过Flask后台手动审核后迁移至正式表。
  
  - **反爬策略**：仅设置基础User-Agent轮换，无代理池。

---

#### **3. 关键功能实现路径**

##### **用户系统**

- **注册/登录**：
  
  - 手机/邮箱注册：Flask接收参数后写入`user`表，密码用`bcrypt`哈希。
  
  - 第三方登录：暂不实现，仅保留基础注册登录。

- **个人中心**：
  
  - 阅读历史：用户每次阅读章节时，Flask直接插入`user_history`表。
  
  - 收藏书架：通过`user_collection`表记录用户与小说的关联。

##### **小说阅读与展示**

- **首页推荐**：
  
  - 轮播图：从`novel`表按更新时间倒序取前5条。
  
  - 榜单数据：每日Flask定时任务从MySQL统计后写入Redis。

- **阅读器功能**：
  
  - 章节内容：通过`chapter`表分页查询，前端实现字体调整/夜间模式（纯CSS）。
  
  - 书签进度：通过`reading_progress`表记录最后阅读章节。

##### **互动与支付**

- **评论系统**：用户提交评论后，Flask直接插入`comments`表。

- **打赏功能**：模拟支付流程，前端调用Flask接口，直接写入`payment`表，无真实支付对接。

##### **管理端**

- **内容审核**：
  
  - 管理员登录后，通过Flask后台查看`crawl_temp`表，手动审核后迁移数据。
  
  - 敏感词过滤：在Flask层通过字符串匹配实现（如`if "敏感词" in content: reject()`）。

- **数据统计**：
  
  - 流量分析：直接通过MySQL的`COUNT`和`GROUP BY`生成日活数据。

---

#### **4. 数据流简化示例**

##### **用户阅读行为**

复制

用户点击章节 → Vue请求Flask接口 → Flask更新`reading_progress`表 → 前端跳转阅读页面

##### **爬虫流程**

复制

管理员访问`/start_crawl` → Flask启动Scrapy爬虫 → 爬虫写入`crawl_temp` → 
管理员审核后点击“通过” → Flask迁移数据至`novel`和`chapter`

##### **榜单生成**

复制

每日凌晨Flask定时任务 → 查询MySQL生成热销榜 → 结果写入Redis → 首页从Redis读取

---

#### **5. 部署与运行**

- **开发环境**：
  
  - 前端：`npm run serve`（Vue开发服务器）。
  
  - 后端：`flask run`（启用调试模式）。
  
  - 数据库：本地安装MySQL+Redis，手动建表。

- **生产环境**：
  
  - 前端：打包为静态文件，托管于Nginx。
  
  - 后端：Gunicorn启动Flask应用。
  
  - 数据库：单机MySQL+Redis，无需主从复制。
