## 测试概述

本测试脚本针对管理模块API进行全面测试，包括：

1. 仪表盘统计功能
2. 用户管理功能
3. 敏感词管理功能
4. 内容审核功能
5. 作者申请管理功能

本测试遵循以下流程：

1. 注册两个测试用户（一个普通用户和一个将成为作者的用户）
2. 使用管理员账户对系统进行管理操作
3. 作者用户经历两次申请流程（先被拒绝，后被批准）
4. 测试用户状态管理和角色变更
5. 测试敏感词管理功能
6. 最终清理测试数据，注销测试用户
