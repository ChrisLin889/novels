## 如何贡献文档

如果您发现文档中有任何错误或需要补充的内容，请按照以下步骤贡献：

1. Fork GitHub仓库
2. 进行必要的文档修改
3. 提交Pull Request，详细说明您的修改
4. 等待审核和合并

## 文档规范

为保持文档的一致性和可读性，请遵循以下规范：

1. 使用Markdown格式编写文档
2. 文档标题使用一级标题(#)
3. 章节使用二级标题(##)
4. 小节使用三级标题(###)
5. 代码块需指定语言类型
6. 图片需添加明确的描述文本
