# 小说平台 API 文档索引

本文档提供了小说平台所有模块的API接口导航，便于开发者快速查找相关接口。

## 模块概述

小说平台API分为以下几个主要模块：

1. **[用户模块](用户模块API文档.md)** - 用户注册、登录、个人信息管理等功能
2. **[作者模块](作者模块API文档.md)** - 作者申请、作者资料管理等功能
3. **[小说模块](小说模块API文档.md)** - 小说和章节的创建、修改、删除等功能
4. **[互动模块](互动模块API文档.md)** - 评论、收藏、阅读历史等功能
5. **[搜索模块](搜索模块API文档.md)** - 内容搜索相关功能
6. **[管理模块](管理模块API文档.md)** - 平台内容管理、用户管理等功能

## 角色权限和功能映射

### 普通用户
- 可访问[用户模块](用户模块API文档.md)的所有功能
- 可访问[互动模块](互动模块API文档.md)中的评论、收藏、阅读历史等功能
- 可访问[搜索模块](搜索模块API文档.md)的搜索功能
- 可申请成为作者（详见[作者模块-提交作者申请](作者模块API文档.md#11-提交作者申请)）

### 作者
- 拥有普通用户的所有权限
- 可访问[作者模块](作者模块API文档.md)的作者资料管理功能
- 可访问[小说模块](小说模块API文档.md)中创建和管理自己作品的功能：
  - [添加小说](小说模块API文档.md#11-添加小说)
  - [更新小说信息](小说模块API文档.md#12-更新小说信息)
  - [添加章节](小说模块API文档.md#21-添加章节)
  - [更新章节](小说模块API文档.md#23-更新章节)
  - [删除章节](小说模块API文档.md#22-删除章节)

### 管理员
- 可访问[管理模块](管理模块API文档.md)的所有功能
- 可处理作者申请（详见[作者模块-处理作者申请](作者模块API文档.md#14-处理作者申请)）
- 可管理所有小说内容（详见[管理模块-内容管理](管理模块API文档.md#4-内容管理)）

## 常见操作流程

1. **作者发布小说流程**
   - 用户提交作者申请 → 管理员审核申请 → 作者创建小说 → 作者添加章节
   - 相关API：[提交作者申请](作者模块API文档.md#11-提交作者申请) → [处理作者申请](作者模块API文档.md#14-处理作者申请) → [添加小说](小说模块API文档.md#11-添加小说) → [添加章节](小说模块API文档.md#21-添加章节)

2. **作者更新内容流程**
   - 作者登录 → 修改小说信息 → 更新章节内容
   - 相关API：[更新小说信息](小说模块API文档.md#12-更新小说信息) → [更新章节](小说模块API文档.md#23-更新章节)

3. **管理员内容审核流程**
   - 管理员查看待审核内容 → 审核通过/拒绝
   - 相关API：[获取待审核内容](管理模块API文档.md#41-获取待审核内容) → [审核内容](管理模块API文档.md#42-审核内容)

## API状态码说明

| 状态码 | 描述               | 说明                                           |
|--------|--------------------|-------------------------------------------------|
| 200    | OK                 | 请求成功                                        |
| 201    | Created            | 资源创建成功                                    |
| 400    | Bad Request        | 请求参数错误                                    |
| 401    | Unauthorized       | 未授权（未登录）                                |
| 403    | Forbidden          | 权限不足                                        |
| 404    | Not Found          | 资源不存在                                      |
| 422    | Unprocessable Entity | 参数验证失败                                  |
| 500    | Server Error       | 服务器内部错误                                  |
