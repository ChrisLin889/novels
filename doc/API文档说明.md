# 小说平台 API 文档说明

本文档是小说平台 API 接口文档的总体说明，提供了平台各个模块的 API 接口使用指南。

## 文档结构

API 文档按照功能模块进行了拆分，包括以下几个部分：

1. [用户模块API文档](./用户模块API文档.md) - 用户注册、登录、个人信息管理等接口
2. [小说模块API文档](./小说模块API文档.md) - 小说管理、章节管理等接口
3. [互动模块API文档](./互动模块API文档.md) - 评论、收藏、关注等社交互动接口
4. [作者模块API文档](./作者模块API文档.md) - 作者申请、作者特有功能等接口
5. [搜索与缓存模块API文档](./搜索与缓存模块API文档.md) - 搜索功能和缓存管理接口
6. [管理模块API文档](./管理模块API文档.md) - 管理员特有的后台管理接口

## 通用说明

### 请求格式

除非特别说明，所有的请求和响应均使用JSON格式。请求时应设置适当的Content-Type：

```
Content-Type: application/json
```

### 认证方式

平台采用JWT（JSON Web Token）认证机制。大部分API接口需要在HTTP请求头中包含令牌：

```
Authorization: Bearer {token}
```

其中，`{token}` 是用户登录后获取的访问令牌。

### 分页机制

支持分页的接口通常接受以下两个查询参数：

- `page`: 页码（从1开始）
- `per_page`: 每页数量

分页响应通常包含以下字段：

```json
{
  "total": 100,      // 总记录数
  "pages": 5,        // 总页数
  "current_page": 1, // 当前页码
  "per_page": 20     // 每页记录数
}
```

### 错误处理

API可能返回以下错误状态码：

| 错误代码 | 描述                        |
|----------|----------------------------|
| 400      | 请求参数错误                |
| 401      | 认证失败或未认证            |
| 403      | 权限不足                    |
| 404      | 资源不存在                  |
| 422      | 请求参数验证失败            |
| 500      | 服务器内部错误              |

错误响应的格式通常为：

```json
{
  "error": "错误信息"
}
```

### 特定功能限制

1. **作者信息更新受限**：无法通过API直接更新作者的pen_name和bio等特有字段
2. **小说添加前提**：添加小说时，必须确保当前用户已有author记录，否则会出现外键约束错误
3. **数据库关系**：
   - user表与author表通过user_id一对一关联（一个用户最多有一个作者身份）
   - novel表通过author_id与author表关联（而非直接与用户关联）

## 接口版本

当前文档描述的是API的1.0版本。API路径不包含版本号，未来可能会通过路径前缀（如`/api/v2/`）引入新版本。
