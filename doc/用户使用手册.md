## 系统简介

本小说网站是基于 Flask + Vue 开发的前后端分离系统，提供了小说阅读、创作、互动等全方位功能。主要特点包括：

- 用户可以浏览、搜索、阅读小说，管理个人书架
- 作者可以发布创作、管理小说章节
- 管理员可以审核内容、管理用户、维护系统
- 响应式设计，支持多种设备访问

## 前端部署运行

### 安装依赖

```bash
cd frontend
npm install
```

### 开发环境运行

```bash
npm run serve
```
开发服务器将在 http://localhost:8080 启动

### 生产环境构建

```bash
npm run build
```
构建后的文件将生成在 `dist` 目录下，可以部署到任何静态文件服务器

## 后端部署运行

### 安装依赖

```bash
cd backend
pip install -r requirements.txt
```

### 配置环境变量

在 backend 目录下创建或修改 `.env` 文件，配置数据库连接信息：

```
DATABASE_URL=mysql://username:password@localhost/novel_db
REDIS_URL=redis://localhost:6379/0
SECRET_KEY=your_secret_key
```

### 初始化数据库

```bash
cd backend
flask db upgrade
```

### 启动服务

开发环境：
```bash
flask run --host=0.0.0.0 --port=5000
```

生产环境：
```bash
gunicorn -w 4 -b 0.0.0.0:5000 run:app
```

## 用户功能

### 注册与登录

1. **注册新账户**
   - 访问网站首页，点击右上角的"注册"按钮
   - 填写用户名、电子邮箱、密码等信息
   - 完成验证步骤，提交注册信息
   - 系统将发送验证邮件到您的邮箱（如已配置）
   - 点击邮件中的验证链接完成注册

2. **登录账户**
   - 点击右上角的"登录"按钮
   - 输入用户名/邮箱和密码
   - 可选择"记住我"功能以保持登录状态
   - 点击"登录"按钮进入系统

3. **找回密码**
   - 在登录页面点击"忘记密码"
   - 输入注册时使用的邮箱
   - 按照邮件中的指引重置密码

### 个人中心

登录后，点击右上角的用户头像可以进入个人中心，包含以下功能：

1. **个人资料管理**
   - 修改头像、昵称、个人简介等基本信息
   - 更新密码、邮箱等账户安全信息
   - 查看账户状态和权限级别

2. **消息通知**
   - 查看系统通知和用户互动消息
   - 管理通知设置

### 书架管理

1. **添加小说到书架**
   - 在小说详情页点击"加入书架"
   - 也可在阅读页面添加

2. **书架分类管理**
   - 创建自定义书架分类
   - 将小说移动到不同分类

3. **书架操作**
   - 移除不需要的小说
   - 调整小说排序
   - 批量管理书架内容

### 阅读历史

1. **查看阅读历史**
   - 在个人中心查看最近阅读的小说
   - 显示上次阅读时间和章节

2. **继续阅读**
   - 点击历史记录中的小说可直接进入上次阅读的章节
   - 系统自动记录阅读进度

### 个人评论

在个人中心可以管理自己发布的所有评论，包括：

1. **查看评论历史**
   - 浏览自己发布的所有评论
   - 按小说分类查看

2. **管理评论**
   - 编辑或删除自己的评论
   - 查看评论获得的回复

## 浏览功能

### 首页推荐

首页提供多种推荐内容：

1. **编辑推荐**
   - 精选优质小说展示
   - 点击可直接进入小说详情页

2. **最新更新**
   - 展示最近更新的小说
   - 包含更新时间和最新章节信息

3. **人气榜单**
   - 展示热门小说排行
   - 基于阅读量、收藏数等数据生成

### 分类浏览

1. **分类导航**
   - 在顶部导航栏选择小说分类
   - 包括玄幻、武侠、都市等多种类型

2. **分类页面功能**
   - 按类型查看小说列表
   - 支持子分类筛选
   - 可按照更新时间、字数、人气等排序

### 排行榜

系统提供多种排行榜：

1. **热门榜**
   - 基于阅读量排序
   - 每日/每周/每月更新

2. **收藏榜**
   - 基于收藏数量排序
   - 反映读者喜好

3. **新书榜**
   - 展示最新发布的小说
   - 发掘新作品

### 搜索功能

1. **快速搜索**
   - 在顶部搜索框输入关键词
   - 支持小说名、作者名、标签等搜索

2. **高级搜索**
   - 多条件组合搜索
   - 按类型、状态、字数等筛选
   - 精确定位所需小说

## 阅读功能

### 小说详情页

小说详情页展示小说的完整信息：

1. **基本信息**
   - 封面、书名、作者、分类、字数等
   - 小说简介和标签

2. **章节列表**
   - 完整的章节目录
   - 支持正序/倒序排列
   - 显示章节更新时间

3. **读者互动**
   - 查看评分和评论
   - 参与讨论和互动

### 阅读器使用

1. **阅读界面**
   - 清爽的阅读环境
   - 可调整字体大小、背景颜色
   - 支持日间/夜间模式切换

2. **阅读控制**
   - 左右滑动或点击屏幕边缘翻页
   - 点击中央呼出菜单
   - 目录快速跳转

3. **阅读设置**
   - 个性化设置字体、行间距
   - 屏幕亮度调节
   - 滚动/翻页模式选择

### 评论互动

1. **发表评论**
   - 在小说详情页底部发表评论
   - 支持文字和表情

2. **回复评论**
   - 回复其他读者的评论
   - 参与讨论互动

3. **评论管理**
   - 编辑和删除自己的评论
   - 举报不良评论

## 作者功能

### 成为作者

1. **申请成为作者**
   - 在个人中心申请作者资格
   - 填写真实姓名和身份证信息
   - 等待管理员审核

2. **作者身份验证**
   - 提交相关证明材料
   - 通过后获得作者权限

### 作品管理

1. **创建新作品**
   - 进入作者中心，点击"创建新小说"
   - 填写小说基本信息，包括标题、分类、简介等
   - 上传封面图片
   - 设置小说状态（连载/完结）

2. **编辑作品信息**
   - 修改小说基本信息
   - 更新小说状态
   - 调整分类和标签

### 章节管理

1. **创建新章节**
   - 在作品管理页面点击"添加章节"
   - 填写章节标题
   - 编写章节内容
   - 设置是否收费和发布时间

2. **编辑章节**
   - 修改已发布章节的内容
   - 调整章节顺序
   - 删除章节（如未有读者阅读）

3. **章节发布设置**
   - 设置定时发布
   - 章节可见性控制

## 管理员功能

### 用户管理

1. **用户列表**
   - 查看所有用户信息
   - 搜索特定用户

2. **用户操作**
   - 封禁/解封用户
   - 修改用户权限
   - 重置用户密码

3. **作者审核**
   - 审核作者申请
   - 查看作者资质材料
   - 授予作者权限

### 内容管理

1. **小说审核**
   - 审核新发布的小说
   - 检查小说是否符合平台规定

2. **章节审核**
   - 审核敏感章节内容
   - 处理违规章节

3. **评论管理**
   - 审核被举报的评论
   - 删除违规评论

### 敏感词管理

1. **敏感词库**
   - 查看和管理敏感词列表
   - 添加新的敏感词

2. **敏感词设置**
   - 设置敏感词过滤级别
   - 配置自动替换规则

## 常见问题

### 账户问题

1. **无法登录**
   - 检查用户名和密码是否正确
   - 确认账户是否被封禁
   - 尝试找回密码

2. **账户安全**
   - 定期修改密码
   - 不要在不信任的设备上保持登录状态

### 阅读问题

1. **阅读进度不同步**
   - 确保登录状态
   - 检查网络连接
   - 手动刷新阅读页面

2. **章节加载失败**
   - 检查网络连接
   - 尝试刷新页面
   - 清除浏览器缓存

### 创作问题

1. **无法发布章节**
   - 确认章节内容不包含敏感词
   - 检查章节标题和内容是否为空
   - 确保账户具有作者权限

2. **作品未通过审核**
   - 查看审核反馈
   - 根据要求修改内容
   - 重新提交审核
