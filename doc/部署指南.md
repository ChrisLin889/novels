## 开发环境部署

开发环境部署主要用于本地开发和测试，配置相对简单。

### 前端部署

1. **安装Node.js**

   确保你的系统已安装Node.js (建议v14+)及npm：

   ```bash
   # 检查Node.js版本
   node -v
   # 检查npm版本
   npm -v
   ```

2. **安装依赖**

   ```bash
   cd frontend
   npm install
   ```

3. **配置环境变量**

   创建或修改`.env.local`文件：

   ```
   VUE_APP_API_BASE_URL=http://localhost:5000/api
   VUE_APP_TITLE=小说网站-开发环境
   ```

4. **启动开发服务器**

   ```bash
   npm run serve
   ```

   启动成功后，可通过 http://localhost:8080 访问前端应用。

### 后端部署

1. **安装Python**

   确保你的系统已安装Python 3.8+：

   ```bash
   # 检查Python版本
   python3 --version
   ```

2. **创建虚拟环境（可选但推荐）**

   ```bash
   cd backend
   python -m venv venv
   
   # Windows激活虚拟环境
   venv\Scripts\activate
   
   # Linux/Mac激活虚拟环境
   source venv/bin/activate
   ```

3. **安装依赖**

   ```bash
   pip install -r requirements.txt
   ```

4. **配置环境变量**

   创建或修改`.env`文件：

   ```
   FLASK_APP=run.py
   FLASK_ENV=development
   DATABASE_URL=mysql://username:password@localhost/novel_db
   REDIS_URL=redis://localhost:6379/0
   SECRET_KEY=your_development_secret_key
   JWT_SECRET_KEY=your_jwt_secret_key
   ```

5. **初始化数据库**

   确保MySQL服务已启动，并已创建`novel_db`数据库：

   ```bash
   # 执行数据库迁移
   flask db upgrade
   
   # 如果是首次运行，可以导入示例数据
   flask seed
   ```

6. **启动后端服务器**

   ```bash
   flask run
   ```

   启动成功后，API服务将运行在 http://localhost:5000

### 数据库配置

1. **安装MySQL**

   ```bash
   # Ubuntu
   sudo apt install mysql-server
   
   # CentOS
   sudo yum install mysql-server
   
   # Mac
   brew install mysql
   ```

2. **创建数据库和用户**

   ```sql
   CREATE DATABASE novel_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   CREATE USER 'novel_user'@'localhost' IDENTIFIED BY 'your_password';
   GRANT ALL PRIVILEGES ON novel_db.* TO 'novel_user'@'localhost';
   FLUSH PRIVILEGES;
   ```

3. **导入初始表结构**

   ```bash
   # 方法1：使用迁移脚本
   cd backend
   flask db upgrade
   
   # 方法2：手动导入SQL文件
   mysql -u novel_user -p novel_db < migrations/create_tables.sql
   ```

### Redis配置

1. **安装Redis**

   ```bash
   # Ubuntu
   sudo apt install redis-server
   
   # CentOS
   sudo yum install redis
   
   # Mac
   brew install redis
   ```

2. **启动Redis服务**

   ```bash
   # 系统服务方式
   sudo systemctl start redis
   
   # 直接启动
   redis-server
   ```

3. **验证Redis连接**

   ```bash
   redis-cli ping
   ```

   如果返回"PONG"，则表示Redis服务运行正常。

## 生产环境部署

生产环境部署需要更加注重安全性、稳定性和性能优化。

### 服务器准备

1. **系统要求**

   - 推荐使用Ubuntu 20.04 LTS或CentOS 8
   - 至少2GB RAM和1核CPU（推荐4GB RAM和2核CPU）
   - 至少20GB磁盘空间

2. **安装基础软件**

   ```bash
   # Ubuntu
   sudo apt update
   sudo apt install python3 python3-pip python3-venv nodejs npm mysql-server redis nginx git
   
   # CentOS
   sudo yum update
   sudo yum install python3 python3-pip nodejs npm mysql-server redis nginx git
   ```

3. **创建应用用户（可选但推荐）**

   ```bash
   sudo useradd -m -s /bin/bash novel_app
   sudo passwd novel_app
   ```

### 代码部署

1. **克隆代码仓库**

   ```bash
   sudo -u novel_app -i
   cd /home/novel_app
   git clone https://github.com/yourusername/novel-website.git
   cd novel-website
   ```

2. **配置前端**

   ```bash
   cd frontend
   npm install
   
   # 创建生产环境变量
   cat > .env.production << EOF
   VUE_APP_API_BASE_URL=https://your-domain.com/api
   VUE_APP_TITLE=小说网站
   EOF
   
   # 构建生产版本
   npm run build
   ```

3. **配置后端**

   ```bash
   cd ../backend
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   pip install gunicorn
   
   # 创建生产环境变量
   cat > .env << EOF
   FLASK_APP=run.py
   FLASK_ENV=production
   DATABASE_URL=mysql://novel_user:password@localhost/novel_db
   REDIS_URL=redis://localhost:6379/0
   SECRET_KEY=your_production_secret_key
   JWT_SECRET_KEY=your_jwt_production_secret_key
   EOF
   ```

4. **初始化数据库**

   ```bash
   flask db upgrade
   ```

### 数据库服务

1. **配置MySQL安全选项**

   ```bash
   sudo mysql_secure_installation
   ```

2. **优化MySQL配置**

   编辑`/etc/mysql/my.cnf`文件，添加性能优化配置：

   ```ini
   [mysqld]
   # 缓冲池大小(根据服务器内存调整)
   innodb_buffer_pool_size = 1G
   # 连接数
   max_connections = 150
   # 查询缓存
   query_cache_size = 64M
   ```

3. **启动并设置自启动**

   ```bash
   sudo systemctl enable mysql
   sudo systemctl start mysql
   ```

### Nginx配置

1. **创建Nginx配置**

   ```bash
   sudo nano /etc/nginx/sites-available/novel-website
   ```

   配置内容：

   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       # 重定向到HTTPS
       return 301 https://$host$request_uri;
   }
   
   server {
       listen 443 ssl;
       server_name your-domain.com;
       
       # SSL配置
       ssl_certificate /etc/ssl/certs/your-domain.crt;
       ssl_certificate_key /etc/ssl/private/your-domain.key;
       ssl_protocols TLSv1.2 TLSv1.3;
       
       # 前端静态文件
       location / {
           root /home/novel_app/novel-website/frontend/dist;
           try_files $uri $uri/ /index.html;
           expires 7d;
           add_header Cache-Control "public, max-age=604800";
       }
       
       # API请求代理
       location /api {
           proxy_pass http://localhost:8000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
       }
       
       # 静态资源缓存
       location ~* \.(jpg|jpeg|png|gif|ico|css|js)$ {
           root /home/novel_app/novel-website/frontend/dist;
           expires 30d;
           add_header Cache-Control "public, max-age=2592000";
       }
   }
   ```

2. **启用配置**

   ```bash
   sudo ln -s /etc/nginx/sites-available/novel-website /etc/nginx/sites-enabled/
   sudo nginx -t
   sudo systemctl restart nginx
   ```

### SSL证书配置

1. **使用Let's Encrypt获取免费证书**

   ```bash
   sudo apt install certbot python3-certbot-nginx
   sudo certbot --nginx -d your-domain.com
   ```

2. **设置自动续期**

   ```bash
   sudo certbot renew --dry-run
   ```

   证书会自动通过cron任务续期。

### 守护进程配置

1. **创建Gunicorn Systemd服务**

   ```bash
   sudo nano /etc/systemd/system/novel-backend.service
   ```

   配置内容：

   ```ini
   [Unit]
   Description=Novel Website Backend
   After=network.target mysql.service redis.service
   
   [Service]
   User=novel_app
   Group=novel_app
   WorkingDirectory=/home/novel_app/novel-website/backend
   Environment="PATH=/home/novel_app/novel-website/backend/venv/bin"
   ExecStart=/home/novel_app/novel-website/backend/venv/bin/gunicorn -w 4 -b 127.0.0.1:8000 run:app
   Restart=always
   RestartSec=5
   
   [Install]
   WantedBy=multi-user.target
   ```

2. **启动并设置自启动**

   ```bash
   sudo systemctl enable novel-backend
   sudo systemctl start novel-backend
   ```

## 部署检查与验证

1. **检查后端服务状态**

   ```bash
   sudo systemctl status novel-backend
   ```

2. **检查Nginx状态**

   ```bash
   sudo systemctl status nginx
   ```

3. **测试API连接**

   ```bash
   curl -k https://your-domain.com/api/health
   ```

4. **检查日志**

   ```bash

   sudo tail -f /var/log/nginx/access.log

   ```

## 常见问题与解决

1. **502 Bad Gateway错误**

   检查Gunicorn服务是否运行：
   ```bash
   sudo systemctl status novel-backend
   ```
   
   查看详细日志：
   ```bash
   sudo journalctl -u novel-backend -n 50
   ```

2. **静态资源加载失败**

   检查Nginx配置中的路径是否正确：
   ```bash
   sudo nginx -t
   ```
   
   检查文件权限：
   ```bash
   sudo chmod -R 755 /home/novel_app/novel-website/frontend/dist
   ```

3. **数据库连接错误**

   检查数据库服务状态：
   ```bash
   sudo systemctl status mysql
   ```
   
   测试数据库连接：
   ```bash
   mysql -u novel_user -p -h localhost novel_db
   ```

4. **API超时**

   可能是Gunicorn工作进程不足，修改配置：
   ```bash
   # 编辑服务文件
   sudo nano /etc/systemd/system/novel-backend.service
   
   # 修改工作进程数，例如从4增加到8
   ExecStart=/home/novel_app/novel-website/backend/venv/bin/gunicorn -w 8 -b 127.0.0.1:8000 run:app
   
   # 重新加载并重启服务
   sudo systemctl daemon-reload
   sudo systemctl restart novel-backend
   ```

5. **内存不足**

   添加交换空间：
   ```bash
   sudo fallocate -l 2G /swapfile
   sudo chmod 600 /swapfile
   sudo mkswap /swapfile
   sudo swapon /swapfile
   echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
   ```
