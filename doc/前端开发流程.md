#### **三、前端开发流程阶段划分**

| **阶段**           | **核心任务**                                       | **交付物**                           |

#### **四、各阶段详细计划**

##### **1. 环境搭建阶段**

- **任务细分**：
  
  ```
  1. 安装Node.js (推荐v16.x)和npm
  2. 全局安装Vue CLI: `npm install -g @vue/cli`
  3. 初始化项目: `vue create novel-website-frontend`
  4. 安装核心依赖: 
     - `npm install axios element-plus vue-router vuex`
     - `npm install -D sass sass-loader`
  5. 配置开发环境变量（区分开发/生产API地址）
  ```

- **质量检查**：
  
  ```
  1. 开发服务器启动验证: `npm run serve`
  2. 确认热更新功能可用
  3. ESLint检查无报错
  ```

##### **2. 组件设计阶段**

- **核心思路**：由小到大，先创建原子组件，再组合为复杂页面

- **关键组件**：
  
  ```
  - NavBar.vue: 导航栏组件，负责站点导航与用户状态显示
  - NovelCard.vue: 小说卡片组件，展示小说封面、标题、简介
  - ChapterList.vue: 章节列表组件，分页展示小说章节
  - CommentItem.vue: 评论项组件，展示评论内容与用户信息
  - Pagination.vue: 分页组件，处理列表翻页逻辑
  ```

- **组件复用原则**：
  
  ```
  1. 将可复用逻辑抽离为组合式函数（Composition API）
  2. 使用Props传递数据，Emit传递事件
  3. 组件样式使用scoped属性隔离
  ```

##### **3. 路由设计阶段**

- **基础路由配置**：
  
  ```javascript
  const routes = [
    { path: '/', component: Home },
    { path: '/novel/:id', component: NovelDetail },
    { path: '/read/:novelId/:chapterId', component: Reader },
    { path: '/login', component: Login },
    { path: '/register', component: Register },
    { 
      path: '/user',
      component: UserCenter,
      meta: { requiresAuth: true },
      children: [
        { path: 'profile', component: UserProfile },
        { path: 'bookshelf', component: UserBookshelf }
      ]
    }
  ]
  ```

- **路由守卫实现**：
  
  ```
  1. 登录状态检查: 拦截requiresAuth页面，重定向至登录页
  2. 阅读记录跟踪: 阅读页面切换时记录阅读位置
  3. 标题动态更新: 根据页面内容设置文档标题
  ```

##### **4. API对接阶段**

- **请求封装**：
  
  ```javascript
  // request.js - Axios基础配置
  const request = axios.create({
    baseURL: process.env.VUE_APP_API_BASE_URL,
    timeout: 5000
  });
  
  // 请求拦截器: 添加认证Token
  request.interceptors.request.use(config => {
    const token = localStorage.getItem('token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  });
  
  // 响应拦截器: 统一错误处理
  request.interceptors.response.use(
    response => response.data,
    error => {
      if (error.response && error.response.status === 401) {
        // 未认证，重定向到登录页
        router.push('/login');
      }
      return Promise.reject(error);
    }
  );
  ```

- **API模块化**：
  
  ```
  1. user.js: 用户注册、登录、信息获取
  2. novel.js: 小说列表、详情、章节内容
  3. comment.js: 评论发布、获取、点赞
  ```

##### **5. 状态管理阶段**

- **Vuex模块设计**：
  
  ```javascript
  // user.js 用户状态模块
  export default {
    state: {
      userInfo: null,
      token: localStorage.getItem('token') || null
    },
    mutations: {
      SET_TOKEN(state, token) {
        state.token = token;
        localStorage.setItem('token', token);
      },
      SET_USER_INFO(state, userInfo) {
        state.userInfo = userInfo;
      },
      LOGOUT(state) {
        state.token = null;
        state.userInfo = null;
        localStorage.removeItem('token');
      }
    },
    actions: {
      async login({ commit }, credentials) {
        const { data } = await userApi.login(credentials);
        commit('SET_TOKEN', data.token);
        commit('SET_USER_INFO', data.userInfo);
      }
    }
  }
  
  // novel.js 小说状态模块
  export default {
    state: {
      recentRead: JSON.parse(localStorage.getItem('recentRead')) || [],
      bookshelf: []
    },
    mutations: {
      ADD_RECENT_READ(state, novel) {
        // 更新最近阅读列表
        const index = state.recentRead.findIndex(item => item.id === novel.id);
        if (index !== -1) {
          state.recentRead.splice(index, 1);
        }
        state.recentRead.unshift(novel);
        state.recentRead = state.recentRead.slice(0, 10); // 保留最近10条
        localStorage.setItem('recentRead', JSON.stringify(state.recentRead));
      }
    }
  }
  ```

##### **6. 页面实现阶段**

- **开发优先级**：
  
  ```
  1. 首页 - 网站入口与第一印象
  2. 小说详情页 - 核心内容展示
  3. 阅读器页面 - 核心功能体验
  4. 登录/注册页 - 用户身份认证
  5. 用户中心 - 个性化功能支持
  ```

- **响应式布局策略**：
  
  ```
  1. 使用Element Plus栅格系统实现基础布局
  2. CSS媒体查询适配不同屏幕尺寸（桌面、平板、手机）
  3. rem或vw单位实现弹性布局
  4. Flex布局处理复杂组件排版
  ```

- **性能优化考虑**：
  
  ```
  1. 路由懒加载减小初始包体积
  2. 关键组件预加载提升用户体验
  3. 长列表使用虚拟滚动优化渲染性能
  ```

#### **五、前后端对接规范**

##### **1. 接口命名规范**

```
GET    /api/novels            # 获取小说列表
GET    /api/novels/:id        # 获取小说详情
GET    /api/novels/:id/chapters # 获取小说章节列表
GET    /api/chapters/:id      # 获取章节内容
POST   /api/users/register    # 用户注册
POST   /api/users/login       # 用户登录
GET    /api/users/profile     # 获取用户信息
POST   /api/comments          # 发表评论
```

##### **2. 数据交互格式**

```json
// 成功响应格式
{
  "code": 0,
  "msg": "success",
  "data": {
    // 具体数据
  }
}

// 错误响应格式
{
  "code": 1001, // 业务错误码
  "msg": "用户名或密码错误",
  "data": null
}
```

##### **3. 认证方式**

```
1. 基于JWT的Token认证:
   - 登录成功后服务端返回token
   - 前端存储token至localStorage
   - 请求时在header中携带: Authorization: Bearer <token>

2. Token过期处理:
   - 响应拦截器检测401状态码
   - 清除本地token并跳转登录页
   - 可选: 实现无感刷新token机制
```

#### **七、前端开发注意事项**

1. **模块化开发**：
   - 确保组件职责单一，遵循单一职责原则
   - 将业务逻辑与UI展示分离，便于维护与测试

2. **代码风格统一**：
   - 使用ESLint保证代码风格一致性
   - 遵循Vue官方风格指南，尤其是组件命名规范

3. **性能考量**：
   - 合理使用computed与watch
   - 避免不必要的组件重渲染
   - 对大量数据的列表使用分页或虚拟滚动

4. **兼容性测试**：
   - 支持Chrome、Firefox、Safari最新版本
   - 移动端适配iOS Safari和Android Chrome

5. **安全措施**：
   - 防止XSS攻击：不直接使用v-html渲染用户输入内容
   - 敏感信息加密：不在本地存储明文密码
   - API参数验证：前端进行基本输入验证，减轻后端压力
