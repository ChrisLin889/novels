# 小说网站 - Novel Website

基于 Flask + Vue 的小说网站毕业设计项目，提供完整的小说阅读、创作和社区互动功能。

![项目截图](frontend/public/images/default_cover.jpg)

## 项目特点

- 🚀 **前后端分离架构**：Vue 3 + Flask实现的高性能应用
- 📚 **完整小说功能**：浏览、阅读、收藏、评论、搜索
- ✍️ **作者创作系统**：小说发布、章节管理、作品数据分析
- 👥 **用户互动社区**：评论、关注、私信、打赏
- 🛡️ **权限管理系统**：普通用户/作者/管理员多级权限
- 🔍 **高效搜索功能**：全文搜索、分类筛选、智能推荐
- 📊 **数据统计分析**：用户行为、阅读偏好、热门内容分析
- 📱 **响应式设计**：适配PC/平板/手机多种设备

## 技术架构

本项目采用前后端分离架构设计：

- **前端**：Vue 3 + Element Plus 构建的响应式界面
- **后端**：Flask + SQLAlchemy 实现的RESTful API服务
- **数据库**：MySQL存储结构化数据，Redis提供缓存支持

## 已完成的模块

目前已经完成开发的核心模块包括：

1. **用户模块**：用户注册/登录、个人信息管理、权限验证（普通用户/作者/管理员）
2. **小说模块**：小说元数据管理、章节内容加载、阅读记录跟踪、分类与榜单生成
3. **互动模块**：评论发布/管理、打赏记录、用户关注、私信功能
4. **缓存模块**：首页榜单缓存（热销榜/新书榜）、高频数据预加载
5. **搜索模块**：关键词全文搜索、高级筛选（分类/字数/更新时间）
6. **管理模块**：内容审核（小说/评论）、用户封禁、敏感词维护、爬虫数据管理
7. **工具模块**：敏感词过滤、数据格式校验、加密工具（密码哈希）
8. **作者模块**：作者认证、作品管理、章节编辑器、作品数据统计

## 前端功能实现

前端已经完成了以下功能的实现：

1. **用户界面**
   - 响应式首页，展示推荐小说、分类和排行榜
   - 用户注册和登录页面
   - 小说详情页，包含章节列表和阅读入口
   - 阅读器页面，支持章节阅读和翻页
   - 用户中心，管理个人信息、书架和阅读历史

2. **作者中心**
   - 作品管理面板，创建和管理小说
   - 章节编辑器，支持富文本编辑和排版
   - 作品数据统计，查看阅读量和收藏数据

3. **管理后台**
   - 独立的管理后台布局，包含侧边栏导航和顶部栏
   - 管理员仪表盘，展示用户、内容和活动统计数据
   - 用户管理功能，支持查看用户列表、封禁/解封用户
   - 内容审核功能，用于审核小说、章节和评论
   - 敏感词管理，维护系统敏感词库
   - 爬取小说管理，查看和管理爬虫获取的小说数据

4. **技术特点**
   - 使用Vuex进行状态管理，包括用户、小说、互动和管理模块
   - 基于Vue Router的路由管理，支持权限控制和页面导航
   - Element Plus组件库提供统一的UI界面
   - 响应式设计，适配不同设备屏幕

## 如何运行

### 后端

1. 安装依赖
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

2. 设置环境变量
   在 `.env` 文件中配置数据库连接

3. 初始化数据库
   ```bash
   flask db upgrade
   ```

4. 运行服务器
   ```bash
   flask run
   ```

### 前端

1. 安装依赖
   ```bash
   cd frontend
   npm install
   ```

2. 运行开发服务器
   ```bash
   npm run serve
   ```

3. 访问应用
   - 用户界面: http://localhost:8080
   - 管理后台: http://localhost:8080/admin (需要管理员权限)

更详细的部署说明请参考[部署指南](./doc/部署指南.md)。
