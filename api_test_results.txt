API Testing Results for Novel Module

Working Endpoints:
1. GET /api/novel/list - Returns a list of novels with pagination
2. GET /api/novel/detail/{id} - Returns novel details and chapters
3. GET /api/novel/chapter/{id} - Returns chapter content with next/prev navigation
4. GET /api/novel/categories - Returns list of all novel categories
5. GET /api/novel/search - Returns search results (empty for tested keywords)
6. GET /api/novel/{id}/chapters - Returns novel info with chapters
7. GET /api/novel/popular - Returns novels sorted by view count (已修复)
8. GET /api/novel/latest - Returns the most recently updated novels (已修复)

Authentication Required Endpoints (Not Tested):
1. POST /api/novel/add - Requires author authentication
2. POST /api/novel/{id}/chapter/add - Requires author authentication
3. PUT /api/novel/{id} - Requires authentication
4. PUT /api/novel/chapter/{id}/update - Requires author authentication
5. DELETE /api/novel/{id}/delete - Requires admin authentication
6. DELETE /api/novel/chapter/{id}/delete - Requires author authentication
7. POST /api/novel/refresh-cache - Requires admin authentication
8. GET /api/novel/my - Requires author authentication
9. GET /api/novel/author/stats - Requires author authentication
