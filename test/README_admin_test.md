# 管理模块 API 测试说明

本文档介绍如何运行和测试管理模块API功能。

## 测试内容

管理模块API测试脚本 (`test_admin_api.py`) 涵盖以下功能：

1. 仪表盘统计功能
2. 用户管理功能
   - 获取用户列表
   - 更新用户角色
   - 管理用户状态（禁用和解禁）
   - 查看用户操作历史
3. 敏感词管理功能
   - 获取敏感词列表
   - 添加敏感词
   - 删除敏感词
4. 内容审核功能
   - 获取待审核内容
5. 作者申请管理功能
   - 获取待处理作者申请
   - 处理作者申请（批准和拒绝）

## 测试流程

测试流程模拟真实的用户场景和管理员操作：

1. 注册两个测试用户（一个普通用户和一个作者用户）
2. 作者用户第一次申请成为作者（将被管理员拒绝）
3. 作者用户第二次申请成为作者（将被管理员批准）
4. 管理员操作（获取数据、管理用户、管理敏感词等）
5. 注销测试用户，恢复系统状态

## 测试准备

### 环境准备

1. 确保API服务已启动并运行在 `http://localhost:5000`
2. 确保测试环境中存在管理员账号（见 `sign.txt`）

### 测试数据

测试脚本将自动创建：
- 随机用户名的测试用户
- 随机敏感词进行测试
- 作者申请记录

测试结束后会自动清理所有创建的测试数据。

## 运行测试

### 单独运行管理模块测试

```bash
cd test
python test_admin_api.py
```

### 运行所有API测试（包括管理模块）

```bash
cd test
python run_api_tests.py
```

### 查看测试报告

测试报告将自动生成在 `doc/test_report` 目录下，包含详细的测试结果和执行情况。

## 注意事项

- 测试过程中会使用管理员账户进行一系列管理操作，请确保在测试环境中运行
- 部分测试功能（如内容审核）依赖于小说模块的功能，如果小说模块未实现，相关测试可能会跳过
- 测试使用的是 `sign.txt` 中的管理员账号，请确保该账号存在且权限正确
