# 用户模块 API 测试说明

本文档介绍如何运行用户模块 API 测试脚本 `test_user_api.py` 并解读测试结果。

## 前提条件

1. 确保后端服务已启动，默认运行在 `localhost:5000` 端口
2. 确保 MySQL 数据库已启动并正常工作
3. 安装必要的 Python 包：
   ```bash
   pip install requests
   ```

## 测试范围

该测试脚本覆盖了 [用户模块API文档](../doc/API/用户模块API文档.md) 中的核心功能：

1. 用户注册
2. 用户登录
3. 获取个人信息
4. 修改个人信息
5. 修改密码
6. 用户注销

## 运行测试

### 执行命令

```bash
cd test
python test_user_api.py
```

### 测试特点

1. **自动化测试**：脚本会自动执行整个用户生命周期的测试
2. **随机测试数据**：每次运行会生成随机的用户名、邮箱和手机号
3. **自清理**：测试完成后会自动注销创建的测试账户
4. **详细日志**：显示每个API请求的响应和测试结果
5. **测试结果摘要**：测试完成后显示成功/失败的测试数量

## 测试输出解读

## 错误处理

如果测试过程中出现错误：

1. **部分测试失败**：脚本会继续执行其他测试，并在摘要中标记失败的测试
2. **关键步骤失败**：如果注册或登录失败，后续依赖这些步骤的测试会被跳过
3. **清理操作**：无论测试成功与否，脚本都会尝试删除创建的测试账户

## 自定义测试

如需自定义测试参数，可以修改脚本开头的配置部分：

```python
# 测试配置
BASE_URL = "http://localhost:5000/api"  # 修改为实际API地址
TEST_USERNAME = f"testuser_{random.randint(1000, 9999)}"  # 可以设置为固定用户名
TEST_PASSWORD = "TestPassword123"  # 可以修改密码
TEST_NEW_PASSWORD = "NewPassword123"  # 可以修改新密码
```

## 问题排查

1. **连接问题**：确保后端服务正在运行，并且可以从测试环境访问
2. **权限问题**：确保数据库有足够权限进行用户的创建和删除
3. **已存在的用户**：如果测试用户已存在，尝试手动删除或修改测试脚本使用不同的用户名
4. **授权问题**：如果获取个人信息等授权相关测试失败，检查JWT令牌配置是否正确
