# 小说测试数据

本目录包含通过API添加的测试小说数据，用于开发和测试小说模块功能。

## 目录内容

- `login_response.json`: 作者账号登录响应
- `token.txt`: 登录获取的JWT令牌
- `categories.json`: 小说分类列表
- `tags.json`: 小说标签列表
- `fantasy_novel.json`: 奇幻小说添加响应
- `scifi_novel.json`: 科幻小说添加响应
- `romance_novel.json`: 言情小说添加响应
- `mystery_novel.json`: 悬疑小说添加响应
- `novel_X_details.json`: 小说详情信息
- `fantasy_chapter.json`: 奇幻小说章节添加响应
- `scifi_chapter.json`: 科幻小说章节添加响应
- `romance_chapter.json`: 言情小说章节添加响应
- `mystery_chapter.json`: 悬疑小说章节添加响应
- `chapter_X_content.json`: 章节内容详情
- `summary.json`: 所有测试小说的摘要信息
